# Sydney Property Map — V81.3

A browser-based interactive property map overlaying live Domain.com.au listings with planning, environmental and infrastructure data across Sydney's growth corridors. Deployed on Vercel with a Neon Postgres database for persistent pipeline and CRM storage.

## Environment Variables (Vercel)
| Variable | Description |
|---|---|
| `DOMAIN_API_KEY` | Domain Developer API key — store in Vercel only, never in code |
| `TESSADEM_API_KEY` | TessaDEM Elevation API key — used by `api/elevation-tile.js` for the Elevation Gradient overlay (V76.11) |
| `POSTGRES_URL` | Neon database connection string (auto-injected by Vercel) |
| `JWT_SECRET` | Session JWT signing secret — minimum 32 random chars. Generate: `openssl rand -base64 48` |
| `ADMIN_FALLBACK_EMAIL` | Break-glass admin email (e.g. `alan.diversi@edanproperty.com.au`). Always has admin access, works even if DB is unreachable |
| `ADMIN_FALLBACK_PASSWORD_HASH` | Bcrypt hash of the fallback admin password. Generate locally with `node scripts/hash-password.mjs` |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob read-write token. Created in Vercel → Storage → Blob. Used by `api/public/lease-offers` Step 2 evidence uploads + `api/evidence-view`/`api/evidence-download` (V77.2) |
| `CRON_SECRET` | Random 32+ char secret. Generate: `openssl rand -base64 48`. Used by `api/cleanup-tokens` to verify daily Vercel Cron requests are legit (V77.2) |
| `RESEND_API_KEY` | Resend API key for outgoing emails. **Optional in V77.2** — `lib/email.js` runs in stubbed mode (writes to `email_log` table, no real dispatch) when not set. Required when V77.3+ swaps to live email |

Button is hidden on the property selector and only appears once a model is loaded. **Workbook structure** (mirrors the on-screen module, not the original feasibility spreadsheet which is long superseded): **(1) Summary** sheet — property address + suburb, state (for stamp duty), generation timestamp, the same 9 KPI tiles shown on screen (Acquisition Price, Comparable Value mean, Total Loan, Cash Required Upfront / Settlement / Total, Net Income Yr 1, Asset Value Exit, NPV at Exit), and run parameters (term, settlement lag, hold pre-reval, LVR, interest, growth rates, cost of capital). **(2) Cashflow** sheet — transposed table matching the on-screen layout: years across, metrics down. Hold-year average column appended where relevant. **(3) Inputs** sheet — every editable model variable grouped into Acquisition & Loan / Growth & Time / Purchase Costs / Operating Expenses / Revenue / Comparable Inputs, with Value + Unit columns. **(4) Comparables** sheet — all four methods (Gross Area, 30% of GRV, Development Estimate, Derived from Yield) with their detail strings, computed values, included Y/N flag, the mean across included methods, and reference values (GRV, NSA, acquisition price). **Live Excel numbers, not display strings** — every monetary cell is a real number with `$#,##0;[Red]($#,##0)` accounting format; percentages use `0.00%;[Red](0.00%)`; integers use `#,##0`; the settlement-lag decimal-years field uses `0.000`.
